LAYER 04
ML Prediction
Engine
Regression / Severity Models
XGBoost / Random Forest models trained to output continuous severity scores (0–100) and risk magnitudes — not binary yes/no outputs.
XGBoost Severity Score
Ensemble Layer
For ambiguous inputs, multiple models run in parallel. Results are aggregated via weighted voting based on confidence scores.
Multi-model Confidence
SHAP Explainer
Computes feature importances for each prediction — shows which clinical variable contributed most to the severity magnitude.
XAI SHAP
↓ severity score + SHAP values
LAYER 05
RAG
Knowledge Base
Vector Database
PubMed abstracts, WHO guidelines, and clinical literature chunked and embedded. Queried dynamically per domain — not pre-scoped to 3 diseases.

Semantic Retriever
Uses SHAP-identified top features as query terms to retrieve the most clinically relevant literature for the specific prediction.
Hybrid search MMR
Hallucination Guard
Faithfulness checker (RAGAS) ensures LLM only cites retrieved documents — never fabricates medical facts.
RAGAS Grounded
↓ grounded evidence + prediction context

⬡ Academic Novelty & Research Contributions

Dynamic domain routing at inference time — no disease hardcoding, making the system generalizable across medical domains.
Severity magnitude outputs (continuous 0–100 scores) instead of binary classification — clinically more useful and academically differentiated.
SHAP-guided RAG retrieval — using explainability values as semantic queries, bridging XAI and retrieval-augmented generation.
RAGAS-evaluated faithfulness loop — quantifiably proving zero hallucination in medical explanations, a key safety research contribution.
Missing-data dialogue agent — conversational clarification loop, relevant to real-world EHR incomplete data challenges.
Modular model registry pattern — hot-swappable ML backends, enabling future expansion to imaging and genomic models.
